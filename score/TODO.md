## 완료된 구현

- **A축(재방문간격·혼잡가중압력)** — `axis_a_pressure.py`. self-exclusion +
  revisit×congestion 상호작용항 반영. 두 raw 값의 단위 스케일 차이(약 400배)를
  population 기준 z-score 정규화로 보정해 재방문압력의 실제 기여비중을
  1.08%에서 약 38.75%로 끌어올렸다. 격자 크기 0.1도·재방문압력 스케일
  60시간은 실측 비교로 확정(CLAUDE.md 확정 규칙 8번).
- **B축(운항 효율)** — `axis_b_physics.py`(Coello et al. 2015 기반 물리식
  연료추정), `axis_b_baseline.py`(LightGBM 기준선 + 잔차). 기준선 입력에서
  평균속도·이동거리를 제외해 물리식 추정치와의 순환성 문제를 해결했다.
- **유사 선박군 그룹핑** — `peer_grouping.py`. 톤수대×어업종×해역×계절 키,
  최소 표본 10척(확정 규칙 9번) 미달 시 `insufficientSample`로 계산 보류.
- **점수조립·금리매핑** — `score_assembly.py::raw_to_score()`,
  `rate_mapping.py`. 금리구간 경계값(78/68/55)은 은행 정책 확정 전 잠정값.
- **요인 기여도(SHAP)** — `shap_factors.py`. A축은 가중합+상호작용항 수식을
  직접 분해(라이브러리 불필요), 실산출 경로(`services/real_scoring.py`)에
  연결 완료. B축은 SHAP이 "기준선 조건 설명"만 가능하고 "효율이 왜 좋은지"는
  설명하지 못한다는 의미론적 한계 때문에 코드를 들어냈다 — 대신 "자기 속도
  vs 유사군 평균 속도" 같은 단순 비교로 설명하는 방향으로 정리(구현 범위 밖).
- **개선 시뮬레이터 트레이드오프 계수** — `tradeoff_coefficients.py`.
  B축 관련 2개는 Coello 물리식(속도 3제곱 법칙)에서 계산해 고정 상수를
  대체했고 `services/scoring.py::simulate()`에 연결 완료. A축 관련 2개는
  근거 공식이 없어 모델링하지 않은 상태임을 명시(0에 가깝게 처리 권장).
- **AIS 위치정보 통계 조회** — `ais_congestion_baseline.py`. (해구, 시간대)
  단위로 집계해 GFW 이벤트 위경도와 공간조인 — 실측 표본 95.9%가 매칭됨.
  다만 `congestion_density_raw` 계산식에 실제로 결합하는 단계는 아직
  안 했다(설계 결정 필요, 아래 항목 참고).
- **실산출 파이프라인 전환** — `services/real_scoring.py`가 `data_new/`
  스냅샷(EEZ 제한 5,323척)을 직접 사용하도록 전환 완료. B축 실산출도
  API에 연결돼 A+B 가중합(0.65/0.35)으로 BlueScore·금리구간까지 나온다.
  매칭 파이프라인 세부 변경 이력은 `data_new/PROCESS_LOG.md` 참고.

## 미해결 · 외부 결정 필요

- **연료식 계수(`POWER_COEFF_A/B`, `SFOC_G_PER_KWH`) 원출처 불명** —
  Coello et al.(2015) 원문에는 해당 회귀식이 없음을 확인했고, 다른 문헌에서도
  출처를 찾지 못했다. TAC 실측 톤수-마력 데이터로 재적합을 시도했으나
  설명력이 낮아(선박마다 kW/GT 비율 편차가 커서) 프로덕션에 넣을 만큼
  신뢰도가 없다고 판단, 기존 문헌값을 잠정 유지한다. 유사 선박군 내
  상대 비교만 쓰므로 계통오차 영향은 제한적이나, 원출처 재탐색이나
  대체 변수(어업종 세분화·선령 등) 검토가 필요하다.
- **`AXIS_A_COST_PER_KNOT` 미검증 계수** — 실측 상관분석 결과 속도와
  재방문간격은 통계적으로 무관하다(Pearson r≈0.0009). 다만 이 계수를
  제거하면 시뮬레이터 곡선이 상한 포화 구간에서 평평해져 변별력을 잃는다는
  걸 확인했다 — 물리 계수가 아니라 "시뮬레이터가 극단값에서 비현실적으로
  보이지 않게 하는 안전장치"로 정직하게 라벨링하고 값은 유지하기로 했다.
  근본적으로는 시뮬레이터 속도 구간 설계 자체를 재검토하는 게 더 나은
  해법일 수 있어 후속 과제로 남긴다.
- **AIS 혼잡도 기준값 결합 방식** — 조회는 가능해졌으나 `congestion_density_raw`
  계산식을 대체/가중평균/이상치 처리 중 무엇으로 보정할지는 팀 논의 필요.
- **B축 필드 매핑** — 톤수(TAC/MOF 값이 둘 다 있을 때 우선순위), 유속
  단위(단위 추정 근거 자체가 없음, 완전 미확인 표시 유지), gearType(국내
  어업종↔GFW 영문 taxonomy 통합 작업 진행 중, 완료 후 재검토). 풍속은
  기상청 관행상 m/s로 추정해 사용 중이나 공식 확인은 아니다.
- **선박제원 매칭 품질** — 상세 현황은 `data_new/TODO.md`·`PROCESS_LOG.md` 참고.
