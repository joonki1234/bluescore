# 담당: 오동규 (조사), 원본 데이터: 김태윤

# 어선 모집단 "90.5% 비어선" 문제 — 해결 방법 조사 (2026-08-18)

## 배경

`data/BlueScore_지희님질문_매칭품질_20260814.md`에서 확인된 문제: GFW가 "한국 어선"이라고
주장하는 31,605척 중, 확정 매칭된 663척(imo_exact+callsign_exact+name_fuzzy)만 봐도
**90.5%(600척)가 국내 등록부 기준으로는 실제 어선이 아니다.**

매칭 방식별로 나눠보면 원인이 매칭 알고리즘이 아니라 GFW 자체 분류 문제 쪽에 무게가
실린다:

| 매칭 방식 | 비어선 비율 |
| --- | --- |
| IMO 완전일치 | 82.4% |
| 콜사인 완전일치 | 98.9% |
| 이름 유사매칭 | 87.6% |

IMO 번호는 전 세계에서 배 한 척당 하나씩 붙는 식별자라 "엉뚱한 배를 잘못 골랐다"로 설명이
안 된다 — GFW가 "한국 어선"이라고 분류해둔 모집단 자체에 비어선이 많이 섞여 있다는 뜻이다.
김태윤님이 발견한 GFW 자기모순 사례("WISE HONEST" = 실제로는 북한 화물선인데 GFW
shiptypes는 어선으로 추정, geartypes 자기신고는 CARGO)도 같은 결론을 뒷받침한다.

참고로 국내 등록부에서 실제로 확보한 어선 데이터 규모: GFW 어업선박 7,327척을 국내
등록부에서 조회 시도 → 레코드가 붙은 것 4,469건(61.0%) → 그 중 실제 "어선" 계열로 분류된
건 **525건(11.7%)뿐**이었다.

## 검토한 해결 방법 5가지와 실측 효과

| # | 방법 | 실측 결과 |
| --- | --- | --- |
| 1 | 확정매칭 663척에 국내 등록부 판정을 실제 필터로 적용 | 그 구간 순도 9.5%→100%. 다만 전체 31,605척 중 663척(2.1%)만 다룸 — 나머지 97.9%는 여전히 미확인 |
| 2 | GFW 자기모순 라벨 필터(`filter_self_contradicting_labels.py`) 전체 적용 | 25척 발견. 확정매칭 663척과 **겹치는 게 0건** — 지금 문제엔 효과 없음, 비용은 0 |
| 3 | 미검증 어선에 "어종 미검증" 표시(정직한 실패 표시) | 데이터 자체는 안 바뀜, 화면 정직성만 개선. 마지막 수단으로 남겨둠 |
| 4 | GFW 조업이벤트 유무로 교차검증 | 비어선(600) 평균 이벤트 102건, 진짜어선(63) 평균 167건 — 중앙값(62 vs 77)도 크게 겹쳐 **판별 기준으로 못 씀**. 화물선 정박/서행을 GFW가 "조업"으로 오탐하는 것으로 추정 |
| 5 | 모집단 뒤집기(국내 등록부 → GFW 방향으로 재출발) | 아래 상세 |

## 방법 5 상세: 모집단 뒤집기

### 국가 단위 어선원부는 없음

해양수산부가 내놓은 관련 데이터셋(연도별 어선현황, 업종별 등록어선통계, 선령별·선종별
등록선박현황)은 전부 **집계 통계**뿐이었다 — "몇 척, 총 몇 톤" 같은 숫자만 있고 개별
어선 식별자가 없다. 이미 폐기 결정된 KOMSA 선박마스터와 같은 패턴.

### 지자체 단위 조사 (8개 지역)

주요 어항 지역 위주로 data.go.kr 및 지자체 자체 포털을 조사했다.

| 지역 | 확인된 데이터셋 | 개별목록 여부 |
| --- | --- | --- |
| **경남 남해군** | 어선등록정보 (파일+오픈API) | ✅ 개별목록 (상세는 아래) |
| 전북특별자치도 | 어선 등록 현황 | ❌ 집계 (시군별 척수 합계) |
| 경기도 | 어선 집계 현황 | ❌ 집계로 추정 |
| 제주특별자치도 | 어선 등록 현황 | ❌ 집계로 추정("톤별·종류별") |
| 부산(강서구/영도구/사상구) | 각 구별 "등록어선 현황" | ❓ 미확인(페이지 접근 실패) |
| 경상남도(도 단위)·경상북도 | 어선현황(연도별) | ❓ 미확인, 집계 계열 이름 패턴 |
| 인천·여수·통영·포항 | — | ❌ 못 찾음 — "지역명+어선" 검색 시 해양경찰청의 **낚시어선**(레저용) 데이터만 나옴, 상업어선 아님 |
| 강원(속초·동해)·충남(서산·태안) | — | ❌ 못 찾음 |

같은 이름 패턴("OO_어선등록정보")으로 재검색해봐도 **남해군이 유일**했다 — 다른 지자체가
같은 틀을 복제해 쓰는 표준화된 서비스가 아니라 예외적인 공개로 보인다.

### 남해군 데이터 상세

- **규모: 2,007척**
- 오픈API + 파일데이터 둘 다 제공, 파일은 CSV 직접 다운로드 가능(인증키 불요),
  실제로 다운로드해 확인 완료 (`https://www.data.go.kr/data/15109574/fileData.do`)
- 갱신: 수시(1회성), 최종 갱신 2025-06-02
- 컬럼(13개): 자료일련번호, **어업방법**, **어선명**, 선적항, 선적항행정동, **마력(PS)**,
  엔진수, 추진기, 조선자, 총톤수, 등록일자, 진수일자, 데이터기준일자
  - 어업방법 필드는 "연안자망어업", "연안통발어업", "연안복합어업", "가두리양식업" 등 —
    지난번 만든 `gear_type_mapping_draft.py`의 19종 카테고리와 상당 부분 겹친다.
  - 마력(PS) 필드까지 있어 기관출력 확보 문제에도 참고가 될 수 있다.

## 파일럿: 남해군 2,007척을 실제로 GFW와 매칭해봄

`data/match_tac_vessels.py`의 로마자화(`romanize_korean`) + 상호최고매칭 로직을 그대로
재사용해(임계값 0.85, rapidfuzz로 고속화) 남해군 어선명을 GFW 자기신고명과 직접 비교했다.

### 결과

| 항목 | 값 |
| --- | --- |
| 남해군 어선 | 2,007척 |
| GFW 모집단 | 31,005척 |
| 상호 최고매칭(임계값 0.85) | **455건** |
| 기존 확정매칭(663척)과 겹침 | **0건 — 전부 신규** |

기존 매칭(주로 원양)과 전혀 안 겹치는 건 예상대로다 — 남해군은 소형 연안어선 위주라
완전히 다른 영역을 커버한다.

### 신뢰도 교차검증 — 결과가 안 좋음

**① 선박 번호 대조** (`numberStatus`, TAC 매칭과 동일 로직): 455건 중

| numberStatus | 건수 |
| --- | --- |
| match(번호까지 일치) | 5 |
| mismatch(번호가 다름 = 사실상 다른 배) | 42 |
| none/one_side_missing(검증 불가) | 408 |

**② 어업방법 대조** (`gear_type_mapping_draft.py` 재활용, GFW의 범용 라벨 "FISHING"만
있는 경우는 비교 불가로 별도 분리):

| 구분 | 건수 |
| --- | --- |
| 일치 | 24 |
| GFW가 범용 라벨뿐이라 비교 불가 | 119 |
| 구체적인 다른 gearType — 진짜 불일치로 추정 | 84 |
| 매핑표에 아예 없는 어업방법(양식업 등) | 228 |

→ **"진짜 비교 가능한" 108건 중 24건(22.2%)만 일치.**

### 결론

**이름 유사도 기반 매칭은 방향을 뒤집어도(국내→GFW) 같은 문제(동명이인)에 부딪힌다.**
"OO호"라는 흔한 한국 어선 이름 패턴 자체가 원인이라, 모집단의 출발점을 진짜 어선으로
보장하는 데는 성공해도(남해군 데이터는 확실히 진짜 어선 목록), 매칭 단계에서 상당수가
틀린 배로 연결될 위험이 여전히 크다. 지자체 데이터가 파편화된 문제(위 8개 지역 조사)에
더해, 설령 좋은 지자체 데이터를 구해도 이 근본 문제는 안 풀린다는 게 실측으로 확인됐다.

## 종합 제안

1. **1단계(즉시 가능)**: 방법 1(확정매칭 663척 필터링 정책 적용) + 방법 2(자기모순
   필터 적용) — 비용 거의 0, 효과는 확실하지만 범위가 좁음(663척 한정).
2. **2단계(모집단 뒤집기)**: 이번 조사로 회수가 낮다는 게 확인됨. 남해군 같은 개별
   사례를 추가로 더 찾아도, 찾는 것 자체가 파편적이고(8개 지역 중 1곳만 성공) 찾아도
   매칭 정확도 문제(22.2%)가 남아 있어 **투입 대비 효과가 낮다.**
3. **3단계(정직한 미검증 표시)**: 위 상황을 감안하면, 매칭 안 된/신뢰도 낮은 어선은
   "어종 미검증"으로 명시적으로 표시하는 쪽이 현실적인 결론에 가깝다. 기획서의
   "모르면 모른다고 한다" 원칙과도 맞는다.
